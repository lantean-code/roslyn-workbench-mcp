# Plugin authoring diagnostics

The `Lantean.Roslyn.Workbench.Mcp.Plugins` package includes `RWMCP001`–`RWMCP023` build-time diagnostics for trusted, in-process plugin authors.

The complete [diagnostics reference](https://lantean-code.github.io/roslyn-workbench-mcp/latest/plugins/diagnostics.html) is maintained in the versioned documentation site. Select the version matching the Host and authoring package you use.

These diagnostics provide early guidance; Host runtime validation remains authoritative when a diagnostic is suppressed or a plugin is built without the analyser. Start with [Your first plugin](https://lantean-code.github.io/roslyn-workbench-mcp/latest/plugin-authoring.html) for a complete example.
