Observed non-default combinations are:

| Purpose | Option differences |
| --- | --- |

| Convert property to auto | editor config prefers auto-properties with suggestion severity |

| Convert `Program.Main` code fix | preceding console shape, plus .NET analyzers and build code-style enforcement, warning severity, and the opposite top-level preference |

The generation-era options record was removed after migration. Consumers now select the corresponding checked-in shape through `InspectionSampleProfile`, so project and editor-config contents are not repeated as strings in test code.

## Implemented stable grouping

The inspection generator became a checked-in base workspace plus explicit, readable profile assets rather than duplicating all 24 documents for every option combination:

- `InspectionSample/Base` contains invariant source files and build configuration.
- `Default`, `NullableDisabled`, `AutoProperties` and `BlockScopedNamespaces` profiles make the library variants explicit.
- `TopLevelToProgramMainRefactoring` and `ProgramMainToTopLevelRefactoring` describe the console refactoring variants.
- `TopLevelToProgramMainCodeFix` and `ProgramMainToTopLevelCodeFix` describe the analyzer-enabled console code-fix variants.
- Profile-local `.asset-delete` manifests select the top-level-only or `Program.Main`-only document set without embedding file names in fixture-generation code.

Profile composition copies bytes from checked-in files. It does not recreate source in C# strings or use broad text substitution. No observed option requires an absolute-path or unique-name token.

## Materialisation policy

- Copy to a unique scenario root containing separate `workspace` and `state` roots.
- Exclude `bin`, `obj`, `.vs` and recovery-state directories at every depth.
- Preserve files with `File.Copy`; do not decode and re-encode them.
- Create runtime-only markers such as the empty `.git` directory after copying.
- Give mutation, external-change, recovery and locking scenarios independent copies.
- Consider class- or collection-scoped sharing only for read-only templates after concurrent query safety is demonstrated.
